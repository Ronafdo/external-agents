# 04: Require a Graph Impact Gate for high-risk changes

**What to build:** Before a developer-authorized high-risk change, the workflow obtains Entire Graph impact evidence, records source/test verification, and provides a concise verified impact brief to the following Aider turn. The finished change includes final semantic-diff evidence and relevant test proof.

**Blocked by:** 02: Capture an isolated, redacted Aider Session journal.

**Status:** ready-for-agent

- [ ] A declared high-risk change cannot proceed through the demo path without a recorded Impact Gate.
- [ ] The resulting brief links Graph findings to developer-verified source or test evidence.
- [ ] Final semantic-diff and test outcomes are captured as Evidence Records.
